# Tracker & Synth DMN/TPN

Este es un sintetizador de pulsos binaurales y generador de ruido marrón diseñado para optimizar el enfoque y la supresión de la Red Neutra por Defecto (DMN).

## Características

- **Sintetizador Binaural**: Generación de frecuencias en tiempo real para inducción de estados Beta.
- **Enmascaramiento Acústico**: Generador de ruido marrón algorítmico para filtrar interrupciones externas.
- **Protocolo de 15 Minutos**: Rastreador de sesión para monitorear la transición de DMN a TPN (Red de Positivo en la Tarea).
- **Análisis Cognitivo**: Proyección en tiempo real del estado mental basado en los parámetros de audio.

## Instalación

1. Clona el repositorio.
2. Navega a `client/` y ejecuta `npm install`.
3. Ejecuta `npm start` para iniciar la aplicación.

## Requisitos de Hardware

Se requiere el uso de **auriculares estéreo** para que el mecanismo neurológico de los pulsos binaurales sea efectivo.
